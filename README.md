# Another One Security For MSPU

## Описание проекта

Another One Security For MSPU — это очередной учебный проект по безопасности для МПГУ на FastAPI, демонстрирующий реализацию базовых механизмов защиты веб-приложений.

### Проект включает:

- регистрацию пользователей;
- безопасную загрузку файлов;
- разграничение доступа к данным;
- защиту от IDOR;
- шифрование файлов;
- логирование событий безопасности;
- sanitization пользовательского ввода;
- защиту через CSP headers.

# Основные возможности

### Безопасная регистрация пользователей

- Пользователи могут регистрироваться через API.
- Для валидации данных используются Pydantic-схемы.

### Безопасная загрузка файлов

Реализована защита от наиболее распространённых атак на file upload:

- ограничение размера файла;
- проверка MIME-type;
- проверка сигнатуры файла;
- whitelist допустимых форматов;
- генерация случайных имён файлов;
- отсутствие использования пользовательского filename.

Поддерживаемые типы файлов:

- PNG
- JPG
- TXT

## Шифрование файлов

Проект поддерживает шифрование загружаемых файлов через:

```python
cryptography.fernet.Fernet
```

# Запуск проекта

## 1. Клонирование репозитория

```bash
git clone <YOUR_REPOSITORY_URL>
cd another_one_security_for_MSPU
```

## 2. Создание .env

```bash
cp .env.example
```

### Заполните переменные окружения.

Пример:
```
APP_SECRET=YOUR_SECRET
FERNET_KEY=YOUR_FERNET_KEY
```

Сгенерировать ключ можно так:
```bash
from cryptography. fernet import Fernet
print(Fernet.generate_key().decode())
```

## 3. 3aпyск через Docker
```bash
docker-compose up -d
```

Приложение будет доступно по адресу `http://localhost:8000`.
